Concurrency Patterns

Concurrency patterns help manage parallel tasks safely and efficiently.

Common Patterns

  • Thread Pool
  • Producer–Consumer
  • Worker Queue
  • Async Pipelines

Thread Pool Example

from concurrent.futures import ThreadPoolExecutor

def task(n):
    return n * n

with ThreadPoolExecutor() as exe:
    results = exe.map(task, range(5))
    print(list(results))
