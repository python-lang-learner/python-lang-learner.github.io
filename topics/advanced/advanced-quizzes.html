Quiz 1: Python Internals

Q: What is the primary role of the Global Interpreter Lock (GIL)?

The GIL ensures that only one thread executes Python bytecode at a time, simplifying memory management but limiting CPU-bound multithreading.

Quiz 2: Memory Optimization

Q: Which feature helps reduce per-instance memory usage?

Using __slots__ prevents the creation of instance dictionaries, reducing memory overhead.

Quiz 3: Concurrency

Q: When should multiprocessing be preferred over threading?

For CPU-bound tasks, as multiprocessing bypasses the GIL and uses multiple cores.

Quiz 4: Async Programming

Q: What type of tasks benefit most from async/await?

I/O-bound tasks such as network calls and file operations.
