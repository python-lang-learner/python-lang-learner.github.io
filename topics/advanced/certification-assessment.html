Section A: Python Internals (MCQs)

1. What is the main purpose of Python’s GIL?

  • A. Improve I/O performance
  • B. Simplify memory management
  • C. Enable multiprocessing
  • D. Speed up CPU-bound code
✔ Correct Answer: B
The GIL ensures safe memory management by allowing one thread to execute bytecode at a time.

2. Which structure stores Python bytecode?

  • A. AST
  • B. Stack frame
  • C. Code object
  • D. Heap
✔ Correct Answer: C

3. Choose the BEST option for handling 10,000 HTTP requests.

  • A. threading

Async I/O handles large numbers of concurrent network operations efficiently.

4. When should multiprocessing be preferred?
