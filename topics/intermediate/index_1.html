List, Dict & Set Comprehensions

Comprehensions provide a compact and readable way to create collections in Python. They are widely used in real-world Python code.

What is a List Comprehension?

A list comprehension allows you to create a new list from an iterable using a single line of code. 

numbers = [1, 2, 3, 4, 5]

squares = [n * n for n in numbers]

print(squares)
✔ Cleaner than loops ✔ Faster execution ✔ Common in interviews & real projects

Conditional Comprehension

You can also apply conditions inside comprehensions. 

even_numbers = [n for n in range(1, 11) if n % 2 == 0]
print(even_numbers)
